# 人声幅值检查与短句自动结束

新建录制和已有任务的「设置」中提供两个独立开关，默认关闭。保存任务设置后，从下一次点击录制本句开始使用新设置，历史录音不会重新检测。已有任务缺少新增字段时仍按关闭处理。

## 采录操作

- **人声幅值检查**：设置人声 RMS 下限和 PEAK 上限，单位 dBFS。−30 / −3 dBFS 是初始参考值，不是验收标准。可输入 −96～0 dBFS，下限须小于上限。
- **短句自动结束**：有效人声之后，连续静音达到任务现有时长就封存本句。沿用 0.2～5 秒、默认 1 秒的静音时长；本模式录制期间修改相关静音参数，从下一次录制本句生效。
- 录制时在固定提示区显示「声音偏小」「声音过大」，同步到提词器，没有提示音或弹窗。完成后可查看整句人声 RMS、PEAK 和发生过的提醒。
- 自动结束后先试听、重录或确认；确认后才按原有规则进入下一句。有幅值提醒时显示「确认保留并录下一句」（最后一句或不连续录制时为「确认保留本句」），保存人工保留时间。
- 人声幅值提醒不阻断导出。声卡中断、写盘失败、检测器失败等问题仍执行原有质量保护，不能用人工保留绕过。
- 静音达标后再说话不会加入已结束的本句，母音频仍持续保存。重录保留旧版本。没有有效人声不会自动生成空录音。

停顿短于设定时长或连续不停顿的多读仍可能被录入；本功能不识别朗读内容、不判断重复次数，也没有新增最长时长提醒。「有效人声」沿用任务的 VAD 或能量检测器，判定能力仍取决于所选检测器及环境。

## 检测与数据

幅值使用与实际写入 WAV 相同的单声道 PCM（含整数 PCM 量化），仅统计检测器判为人声的采样区间，不使用界面平滑电平。非人声区间不计入整句 RMS，也会清空实时低音量计时。

实时低音量使用 200 毫秒滚动 RMS，低于下限持续 300 毫秒后记录提醒；峰值超过上限即记录提醒。阈值相等不告警。结束时再次按整句人声能量和最大峰值计算，短于 200 毫秒的人声也会检查。实时提醒即使随后恢复正常仍保留。

任务快照的 `recording_policy` 保存两个开关及阈值。每个录音版本保存本次 `recording_policy`、`speech_quality` 和 `end_reason`：

| 字段 | 含义 |
| --- | --- |
| `speech_samples` | 检测为人声并参与幅值计算的样本数 |
| `rms_dbfs` / `peak_dbfs` | 整句人声 RMS / 最大绝对峰值；无可用人声时为空 |
| `warnings` | 整句检查结果，`speech_low` / `speech_high` |
| `live_warnings` | 录制过程中发生过的幅值提醒 |
| `policy` | 本次幅值检查所用开关和阈值 |
| `retained_by_operator_at` | 有幅值提醒的录音被人工确认保留的时间 |
| `end_reason` | `manual`、`auto_silence`、`interrupted` 或 `detector_failure` |

幅值警告和阻断性的 `quality_issues` 分开保存。检测失败或写盘故障时不伪造完整幅值结果。历史录音缺失的结果不补算。母音频与切片导出的元数据均携带新增信息。

Rust 分析线程只锁定自动结束采样位置，命令主循环串行执行封存。手动结束与自动结束复用封存逻辑；带 `attempt_id` 的旧结束请求只能返回该旧版本，不能结束新版本。异常退出时通过 `attempt_started` 日志恢复本次配置并标为中断，不自动确认。

## 验证入口

- `npm run typecheck`：前端与 Electron 类型。
- `npm run test:electron`：协议中间层、录制流程、历史与导出等回归，包含旧版本结束请求去重。
- `node scripts/run-cargo.cjs test --manifest-path engine/Cargo.toml --features system-test`：真实 PCM、两种检测器、固定终点、设置延期生效、人工保留落盘、故障保护和恢复。
- `npm run test:speech-ui`：模拟引擎下的界面、提词器提醒、默认开关及设置生效时机；默认使用已安装的 Chrome。
- `npm run test:e2e:electron`：真实 Electron 与测试引擎集成，包括自动结束、短停顿继续、多读发生在终点后、人工保留及延迟手动结束请求。
- `npm run test:engine-protocol`、`npm run test:crash-recovery`、`npm run test:engine-system`：协议、崩溃恢复与系统故障回归。

## Windows 外置声卡实录验收（待现场执行）

使用实际生产声卡、采样格式和唤醒词脚本，分别录正常音量、偏小、超限、短促发声、长静音及环境噪声。检查提示出现时机、提词器同步，以及导出 WAV 中的人声与静音边界。对照实际参考阈值检查边界相等时无误报。

分别在静音达标前后多读，验证达标前会继续录入、达标后当前句不会改变；不发声不产生空录音，自动结束后必须人工确认。并测试自动结束时点击完成、断开声卡、写盘故障、重录已有合格版本、重启后检查人工保留记录及导出元数据。自动化测试不能替代这项硬件验收。
