## 兼容与验证边界

- 旧任务的幅值、自动结束开关仍默认关闭；旧录音不补算、不重判。现有中断强制补录规则、母音频保存和历史版本保留继续有效。
- 旧授权首次迁移需要本机仍匹配签名机器码；迁移后保留原有硬件变化容错。旧明文记录无法证明历史组件的真实性，因此不能凭旧数组直接迁移已变更硬件的机器。
- 授权备份涉及 `license.key`、`license.json` 和 `license.json.clock`，恢复须使用原系统用户环境。系统安全存储不可用或受保护记录损坏时不放行。离线本地存储不提供对管理员控制整套系统快照、系统时间或应用程序的绝对防回滚保证；本次修复针对审计中的文件编辑与重新激活绕过。
- 本机工具链已恢复。尚无真实 Windows 外置声卡试录证据，唤醒词提示时机、切片内容、设备拔插和驱动异常仍需在目标 Windows 工位完成；macOS 回归与模拟 Windows 缩放不替代该项验收。
- 本轮未发布安装包，也未修改客户真实采录数据或实际授权记录。
